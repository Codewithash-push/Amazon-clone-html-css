# Amazon Clone 🛒

A responsive Amazon homepage clone built using HTML and CSS.
This project recreates the basic user interface of Amazon, including the navigation bar, product sections, banners, and footer layout.

## Features

* Responsive homepage design
* Amazon-style navigation bar
* Product cards and sections
* Search bar UI
* Banner and hero section
* Footer layout similar to Amazon
* Clean and beginner-friendly frontend project

## Technologies Used

* HTML
* CSS
* Visual Studio Code

## Project Purpose

This project was created to improve frontend web development skills by practicing layout design, styling, positioning, flexbox, and responsive UI development.

* Shopping cart functionality
